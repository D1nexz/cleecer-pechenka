# 🍪 Кликер печеньки (Cookie Detector)

Автоматический кликер для "печеньки" на основе нейросети **YOLOv8**. Проект делает скриншоты экрана, распознаёт печеньку, кнопки прокачки и бонусы, а затем автоматически кликает по ним.

## 📋 Содержимое проекта

| Файл | Назначение |
|---|---|
| [`app.py`](app.py) | Главный скрипт — распознавание и клики (кликер) |
| [`screener.py`](screener.py) | Сбор скриншотов для датасета |
| [`train.py`](train.py) | Обучение модели YOLOv8 |
| [`data.yaml`](data.yaml) | Конфигурация датасета (3 класса: `game`, `upgrade LvL`, `bonus`) |
| [`requirements.txt`](requirements.txt) | Список библиотек для установки |
| [`runs/detect/cookie_detector/weights/best.pt`](runs/detect/cookie_detector/weights/best.pt) | Готовая обученная модель (переобучать НЕ нужно) |
| `images/`, `labels/` | Датасет: скриншоты и разметка |

## ⚙️ Требования

- **Windows** (рекомендуемая платформа) или **Linux** (только X11-сессия)
- **Python 3.8+** — скачать с [python.org](https://www.python.org/downloads/)
  > ⚠️ При установке Python обязательно отметьте галочку **"Add Python to PATH"** (Windows).

## 📦 Установка библиотек

Откройте **терминал** в папке проекта и выполните:

### Вариант 1 — установить всё сразу (рекомендуется)

```
pip install -r requirements.txt
```

### Вариант 2 — установить по одной

```
pip install ultralytics
pip install opencv-python
pip install numpy
pip install pillow
pip install pyautogui
pip install mss
```

### Полный список библиотек

| Библиотека | Для чего нужна |
|---|---|
| `ultralytics` | Нейросеть YOLOv8 — обучение и распознавание |
| `opencv-python` (`cv2`) | Обработка изображений и скриншотов |
| `numpy` | Работа с массивами данных |
| `pillow` | Библиотека изображений (для скриншотов) |

| `mss` | Быстрые скриншоты (на Linux — **без** необходимости ставить `scrot`) |

### (Необязательно) Ускорение на видеокарте NVIDIA

Обычная установка использует CPU — работает, но медленнее. Для работы на GPU сначала установите:

```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

Затем установите остальные библиотеки из `requirements.txt`.

## 🐧 Linux

Проект поддерживает **Linux** (X11, не Wayland). Скрипты автоматически определяют ОС и переключаются на `mss` для скриншотов.

### Первоначальная настройка на Linux

Установите системные пакеты для `pyautogui` (нужен для управления мышью, на X11):

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y python3-xlib scrot

# Fedora
sudo dnf install python3-xlib scrot

# Arch Linux
sudo pacman -S python-xlib scrot
```

Затем установите Python-библиотеки:

```bash
pip install -r requirements.txt
```

### Важно
- **Только X11.** Запускайте в X11-сессии: при входе в систему выберите **"Ubuntu on Xorg"** / **"GNOME on Xorg"**. Wayland-сессия не поддерживается — скрипты выведут предупреждение при запуске.
- **Нужен графический сеанс (`DISPLAY`).** Кликер не работает на headless-сервере без экрана.
- **Масштабирование экрана:** на Linux нет DPI-фикса (Windows-only), поэтому если масштаб системы отличается от 100%, координаты скриншотов могут не совпасть с физическими пикселями экрана, на которых обучалась модель.

## 🚀 Запуск

Перейдите в папку проекта и запустите нужный скрипт:

**Windows:**
```
cd C:\путь\к\папке\cookie-detector-master
python app.py
```

**Linux:**
```
cd /путь/к/папке/cleecer-pechenka
python app.py
```

| Скрипт | Команда | Что делает |
|---|---|---|
| Кликер печеньки | `python app.py` | Распознаёт печеньку и кликает |
| Сбор скриншотов | `python screener.py` | Делает скриншот каждые 5 секунд |
| Обучение модели | `python train.py` | Переобучает модель на датасете |

> 💡 Модель уже обучена — файл `runs/detect/cookie_detector/weights/best.pt`. Просто запустите `python app.py`, обучать заново не нужно.

### 🎮 Управление ботом — пробел

Бот управляется **клавишей Пробел** (слушатель работает глобально, из любого окна):

1. Первое нажатие **Пробела** — бот начинает кликать.
2. Повторное нажатие **Пробела** — бот останавливается (печатает статистику и завершает программу).

`Ctrl+C` тоже работает, рывок мыши в угол экрана — экстренная остановка (`pyautogui.FAILSAFE`).

## ❓ Частые проблемы

- **Пробел не реагирует** — установите библиотеку `pynput` (`pip install pynput`); на macOS дополнительно дайте приложению разрешение «Ввод с клавиатуры / Input Monitoring».
- **Ошибка про DPI / скриншот не в том разрешении (Windows)** — [`app.py`](app.py) автоматически включает DPI-awareness, скриншоты делаются в физическом разрешении.
- **Не распознаёт печеньку** — проверьте, что на экране открыта игра и курсор не в углу экрана (там сработает экстренная остановка `pyautogui.FAILSAFE`).
- **Ошибка "Не найдена модель"** — убедитесь, что папка `runs/detect/cookie_detector/weights/` содержит `best.pt`.
- **"no display name" / DISPLAY не задан (Linux)** — кликеру нужен запущенный графический сеанс. Запускайте внутри X11-десктопа.
- **Скриншоты не работают (Linux, Wayland)** — переключитесь на X11-сессию.
- **Модель работает, но клики бьют мимо (Linux)** — проверьте настройки масштабирования (Scale). Если масштаб > 100%, координаты детекций `mss` могут не совпадать с теми, на которых обучалась модель.
